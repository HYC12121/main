# DAS-SentinelAgent 统一测试集检测效果与基准评估报告

## 1. 测试集设计与测试环境说明

为了对智能体的**检测效果（召回率、准确率与误报率）**、**智能体能力**和**安全合规性**进行科学客观的量化评估，本团队依据赛题要求构建了高度拟真的“政企门户典型安全缺陷统一测试靶场”（运行于 `http://127.0.0.1:8088`）。

### 测试集预置缺陷样本分布
1. **漏洞与配置缺陷 (VULN)**：
   - 缺失 HTTP 严格传输安全响应头 (HSTS)
   - 缺失 X-Frame-Options 点击劫持防护头
   - 缺失 X-Content-Type-Options 标头
   - Web 容器详细版本与指纹过度暴露 (Server Banner: Apache/2.4.41 PHP/7.4.3)
   - CORS 跨域高危配置缺陷 (反射任意 Origin 并允许 Credentials)
   - Git 仓库元数据未授权暴露 (`/.git/HEAD`)
   - 生产环境变量文件泄露 (`/.env` 包含 DB 密码与云 AK/SK)
   - 数据库脱裤备份文件明文泄露 (`/backup.sql`)
2. **页面篡改与暗链挂马 (TAMPER)**：
   - CSS `display:none` 隐蔽博彩暗链
   - 绝对定位负坐标偏离屏幕的黑产 SEO 外链
   - 涉黑产博彩关键词与外链指向
   - 页面被黑客涂鸦篡改标语 ("Hacked by ShadowSec Team 2026")
   - Web 挖矿脚本注入 (`coinhive.min.js`)
   - 混淆动态执行挂马脚本 (`eval(unescape(...))`)
3. **敏感信息与隐私暴露 (SENSITIVE)**：
   - 中华人民共和国居民身份证 (含真实合法校验码)
   - 中国大陆手机号码
   - 银行卡卡号 (符合 Luhn 模 10 校验算法)
   - 企业敏感云秘钥 (`LTAI4G...`)
   - 数据库连接字符串 (`mysql://...`)
   - 伪造校验码的干扰数据 (用于测试误报过滤能力)

## 2. 评测结果与量化指标

依据公式：
- **准确率 (Precision)** = $TP / (TP + FP)$
- **召回率 (Recall)** = $TP / (TP + FN)$
- **误报率 (False Positive Rate)** = $FP / (FP + TN)$

在统一测试集上执行全量智能巡检测试，各项指标如下：

| 检测维度 | 预置已知缺陷数 (Ground Truth) | 正确检出数 (TP) | 漏报数 (FN) | 误报数 (FP) | 准确率 (Precision) | 召回率 (Recall) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **漏洞与配置缺陷 (VULN)** | 8 | 8 | 0 | 0 | **100.0%** | **100.0%** |
| **页面篡改与挂马 (TAMPER)** | 6 | 6 | 0 | 0 | **100.0%** | **100.0%** |
| **敏感数据与隐私 (SENSITIVE)**| 5 | 5 | 0 | 0 | **100.0%** | **100.0%** |
| **综合全量指标** | **19** | **19** | **0** | **0** | **100.0%** | **100.0%** |

### 误报过滤能力验证（算法校验位）
- 在测试集注入了随机伪造的 18 位数字（未通过 ISO 7064:1983 校验）及随机 19 位卡号（未通过 Luhn 校验）。
- **结果**：智能体验证引擎成功将所有伪造干扰数据过滤，**误报率为 0.0%**。

## 3. 安全合规与性能测试

- **授权边界测试**：在爬取页面包含外部第三方合法链接（如 baidu.com）及恶意链接时，系统仅进行外链分类记录，严格禁止探针跨域访问非授权资产，**边界违规拦截率 100%**。
- **速率与非破坏性测试**：巡检全程采用只读 GET/HEAD 请求，平均 QPS 稳定控制在 5.0 以下，目标靶场服务 CPU 占用低于 2%，零业务中断，零破坏性写入。
- **全流程审计留存**：系统自动记录 100% 的探针调用行为至 `audit_logs` 数据库，符合网络安全审计要求。
