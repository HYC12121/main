# DAS-SentinelAgent (安恒星巡) 系统架构与智能体交互规范

## 1. 系统总体架构

## 2. 智能体工作流 (Agent Workflow Lifecycle)

1. **意图理解与任务规划 (ReAct Step 1)**：
   - 接收用户自然语言指令或定时 Cron 信号；
   - 提取目标站点 URL、授权白名单边界、单位特定敏感关键词与限制参数；
   - 执行最小权限与安全合规校验。
2. **资产发现与资源测绘 (ReAct Step 2)**：
   - 异步并发广度优先爬取目标 URL，解析 HTML 结构、动态 JS 文件、API 路由；
   - 生成 DOM 结构 Hash 与内容特征指纹，建立资产全景拓扑。
3. **开源工具编排与探针并行扫描 (ReAct Step 3)**：
   - 漏洞探针：检查 Security Headers、CORS 任意 Origin 反射、.git/.env/backup 等配置泄露；
   - 篡改与挂马探针：扫描隐藏暗链 (`display:none`、负坐标)、涉黑博彩外链、挖矿 JS 脚本、涂鸦篡改词汇；
   - 敏感信息探针：结合 ISO 7064:1983.MOD 11-2 身份证校验、Luhn 银行卡校验、手机号前缀、云厂商 AK/SK、数据库连接串及自定义企业规则。
4. **智能研判与去重定级 (ReAct Step 4)**：
   - 基于 `(category, title, path, param)` 泛化聚合去重；
   - 根据 CVSS 与企业安全标准划分 CRITICAL / HIGH / MEDIUM / LOW 等级并计算系统安全态势分 (0-100)；
   - 自动生成上下文脱敏证据链及 Nginx/代码级专家整改建议。
5. **基线对比与运营闭环 (ReAct Step 5)**：
   - 保存当前快照与历史基线比对，提取“新增风险”、“已闭环修复风险”、“DOM 异动页面”；
   - 触发 Webhook / 钉钉告警并生成完整可视化合规报告。
